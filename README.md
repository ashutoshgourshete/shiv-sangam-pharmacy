MAHA/10600/Latur) ही समाजप्रबोधन, शैक्षणिक विकास, युवकांचे सक्षमीकरण आणि उच्च शिक्षणाच्या प्रसारासाठी अविरत कार्य करणारी एक प्रतिष्ठित सामाजिक व शैक्षणिक संस्था आहे. स्वामी विवेकानंदांच्या सेवाभावी आणि राष्ट्रनिर्मितीच्या तत्त्वांवर विश्वास ठेवून संस्थेने आरोग्य व वैद्यकीय शिक्षणाचा विस्तार केला आहे.
